## 三、下一步计划

### 立即（本周）

| 优先级 | 事项 | 说明 |
|---|---|---|
| 🔴 P0 | 仓库切换 Public → GitHub Pages 上线 | 当前 Private 仓库无法启用 Pages |
| 🟡 P1 | 页面添加反馈入口 | 底部加 "💬 反馈" 链接 → 飞书/问卷/GitHub Issues |
| 🟡 P1 | 分享链接，收第一批反馈 | 发朋友圈/群/论坛，观察自然使用行为 |

### Phase 1 — LLM 解析验证（预计 2-3 周）

| 事项 | 说明 |
|---|---|
| LLM 接口封装 | OpenAI / Claude API → "自然语言 → 结构化布局需求" 翻译 |
| 需求结构化 Schema | 定义输入格式：房间尺寸、家具清单、约束条件（"床不靠窗"） |
| Prompt 工程 | 设计几组 prompt，测试解析准确率 |
| 解析结果可视化 | 将解析结果回填到编辑器中（预填充房间 + 家具） |
| 验收标准 | 10 个真实需求 → 解析准确率 > 80%，否则降级为手动输入 |

### Phase 2 — 约束求解引擎（预计 3-5 周）

| 事项 | 说明 |
|---|---|
| 约束形式化 | 将"床不靠窗"翻译为数学不等式 |
| 求解器选型 | 评估纯 JS 实现 vs 编译到 WASM |
| 多方案生成 | 同一输入生成 2-3 套不同布局 |
| 方案评分 | 空间利用率、动线流畅度、采光等维度打分 |

### Phase 3 — 界面整合上线（预计 3-4 周）

| 事项 | 说明 |
|---|---|
| 自然语言输入框 | 集成到编辑器页面顶部 |
| 方案浏览器 | 2-3 套方案左右对比，点选加载 |
| 移动端适配 | 响应式布局，触屏手势 |
| 性能优化 | 视口裁剪、离屏 Canvas |

### Phase 4 — 端到端验证 + 商业化（预计 2-4 周）

| 事项 | 说明 |
|---|---|
| 真实用户测试 | 50 人内测 → 迭代 |
| 付费模型 | 免费 3 次/天 + 会员不限次 |
| 部署优化 | 国内 CDN、备案域名 |
