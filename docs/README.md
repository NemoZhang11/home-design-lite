```

├── 产品需求和项目管理/                 ← 方案设计
```

## 📝 使用方式

当前会话只做文档和反馈检查，不做实际开发。

**定期检查流程：**
1. 打开 `PROGRESS.md` 查看最新进展
2. 检查 `反馈与迭代/反馈记录.md` 查看用户反馈和 bug 状态
3. 如有方案变更，更新对应设计文档并记录到反馈记录中
