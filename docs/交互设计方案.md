# 交互设计方案

> 版本: v5.0 | 2026-07-27
> 聚焦核心布局图绘制，单房间，交互流畅度优先。

---

## 一、用户与操作循环

### 用户画像

普通业主——"我家次卧 3×4m，有门有窗，要放床、衣柜、书桌，怎么摆合理？"
想要一张带尺寸的平面图，不想学工具怎么用。

### 用户的真实操作

不是线性流程，而是**反复调整的循环**：

```
设房间 ──→ 选家具 ──→ 看布局 ──→ 微调 ──→ 再看布局 ──→ 导出
  ↑          ↑           ↑          ↑            ↑
  └─ 随时改 ─┴─ 随时增减 ─┴─ 随时重排 ┴─ 随手拖拽 ─┘
```

四个标签始终可点击，不限制顺序。标签上没有数字编号，每个面板底部没有"下一步"。

## 三、画布操控（核心流畅度）

### 3.1 一键铺满画布

右下角常驻 **[⊞ 铺满画布]** 按钮，旁边显示当前缩放比例 `[83%]`。

**算法**：
```
1. 取房间包围盒宽高 (roomW, roomH)，含墙体厚度
2. 可用区域 = 画布容器尺寸 - 40px 内边距
3. scale = min(availW / roomW, availH / roomH)
4. 将 stage 缩放到 scale，平移到居中
5. 动画 300ms ease-out
6. 更新缩放比例显示
```

**触发时机**：点击按钮 / `Ctrl+0` / **创建或切换房间后自动执行一次**

### 3.2 滚轮缩放

```
以鼠标指针为中心缩放:
  factor = deltaY > 0 ? 0.92 : 1.08
  newScale = clamp(old * factor, 0.2, 4.0)
  鼠标指向点在画布上的位置保持不变
```

右下角缩放比例随滚轮实时更新：`[45%]` `[100%]` `[200%]`
双击缩放比例数字 → 重置到 100%。

### 3.3 平移画布

| 操作 | 行为 |
|------|------|
| 鼠标中键按下 + 拖拽 | 平移 |
| 空格 + 左键拖拽 | 平移（替代方案） |
| 触控板双指滑动 | 平移 |

光标：`grab` / `grabbing`。

### 3.4 完整光标表

| 场景 | 光标 | 用户感知 |
|------|------|---------|
| 画布空白区域 | `default` | "这里没东西" |

│ │ 书房  │ │ 客厅  │        │
│ │3×3m  │ │6×4m  │        │
│ └──────┘ └──────┘        │
│                           │
│ ┌───────────────────────┐ │
│ │ ✏️ 自定义尺寸          │ │
│ │ 宽 [400]  长 [300] cm │ │
│ │      [ 创建房间 ]     │ │
│ └───────────────────────┘ │
│                           │
│ ── 当前房间 ──             │
│ 400×300 cm │ 门×1 窗×1   │

│                           │
│ [✏️ 手动绘制墙线]           │

```

**关键 UX 细节**：

切换模板或改尺寸时，**如果已有房间** → 弹出确认："当前房间将被替换，确定吗？" 点确认后再创建。防止误操作丢失已有设计。

"重置房间"按钮 → 清空当前房间回到初始状态（相当于"新建"）。

### 三种创建方式

| 方式 | 位置 | 谁用 |
|------|------|------|
| 快速模板 | 顶部卡片 | 大多数用户，点一下即得 |
| 自定义尺寸 | 中部表单 | 知道确切尺寸的用户 |
| 手动绘制 | 底部按钮 | 极少数用户，保留但不喧宾夺主 |

创建后**自动执行铺满画布**。

### 门窗放置

两种激活方式（用户任选）：
1. **双击墙面** → 弹出菜单
2. **单击墙段** → 墙段上浮现 `+` 按钮 → 点击

弹出菜单：
```
┌──────────────┐
│ 🚪 添加门    │
│ 🪟 添加窗户  │
└──────────────┘
```

选中后交互：

```
        ←→ 拖拽边缘调宽
   ─ ─ ─┐     ┌──墙线
        │ 🚪  │      ← 拖拽主体沿墙移动
   ─ ─ ─┘     └──墙线
         \    ← 点击弧线切换内外开
  浮层: ←→ 80cm
```

| 操作 | 方式 |
|------|------|
| 沿墙移动 | 拖拽主体 |
| 调宽度 | 拖拽左右边缘（40-200cm 范围限制） |
| 切换内外开（门） | 点击弧线 |
| 切换铰链侧（门） | 双击门图形 |
| 删除 | Delete 键 / × 按钮 |
| 取消选中 | 点击空白 / Esc |

**防重叠**：在已有门/窗的墙段上添加时 → 自动偏移到不重叠的位置。如果整面墙已满 → 提示"这面墙已没有足够空间"。

## 五、🪑 选择家具

### 左侧面板

```
┌───────────────────────────┐
│ 需要哪些家具？选好自动排进房间 │
│                           │
│ ┌───────────────────────┐ │
│ │ 🛏️ 床    160×200     │ │
│ │          数量 [1]     │ │
│ ├───────────────────────┤ │
│ │ 📝 书桌  120×60      │ │
│ │          数量 [0]     │ │
│ ├───────────────────────┤ │
│ │ 🗄️ 衣柜  100×60      │ │
│ │          数量 [1]     │ │
│ ├───────────────────────┤ │
│ │ 💺 椅子   40×40      │ │
│ │          数量 [2]     │ │
│ ├───────────────────────┤ │
│ │ 🛋️ 沙发  180×80      │ │
│ │          数量 [0]     │ │
│ └───────────────────────┘ │
│                           │
│ 已选: 床×1 衣柜×1 椅子×2   │
│ ┌───────────────────────┐ │
│ │  ✨ 排一下 (4件)       │ │
│ └───────────────────────┘ │
├───────────────────────────┤
│ [清空选择]                  │  ← 一键清零
└───────────────────────────┘
```

**选择逻辑**：用 [+] 而非拖拽。因为用户此时不知道家具放哪里——先决定"要什么"，再看"怎么摆"。

**交互细节**：
- 点击 [+] 区域（**点击区 ≥ 32px**，防误触）→ 数量 +1
- 点击数字可手动输入（1-99）
- 设为 0 → 画布上的轮廓消失
- 同类多件标注 "衣柜 #1" "#2"
- 点击"清空选择" → 所有数量归零

**画布反馈**：
- 已选家具在房间右侧临时区显示**半透明灰色轮廓**，标注名称
- 轮廓仅用于感知大小比例，不决定最终位置
- 增减数量时轮廓即时增减

**"排一下"按钮**：≥1 件时可点击 → 执行布局 → 自动切换到"✨ 布局方案"标签

### 左侧面板

```
┌───────────────────────────┐
│ ┌───────────────────────┐ │
│ │ ● 方案A ★推荐          │ │
│ │   家具贴墙放,中间宽敞   │ │

│ 操作提示: ← → 方向键切换    │
└───────────────────────────┘
```

**方案描述**用**大白话**而非抽象词：
- ❌ "靠墙紧凑" → ✅ "家具贴墙放，中间宽敞"
- ❌ "分区布局" → ✅ "分区布局，动静分离"
- ❌ "居中宽敞" → ✅ "居中摆放，四面通行"

**布局生成**：纯前端 < 50ms，**不做假加载动画**。点击即出。

**方案切换**：
1. 点击左侧方案卡片
2. 键盘 ← →
3. 画布左右边缘小箭头（hover 显现）

**切换方案时，如果 Step 4 有未保存的微调** → 弹出确认："切换方案将丢弃当前的微调修改"。

**"↺ 恢复默认"**：如果用户在 Step 4 做了微调，点此回到当前方案的算法原始布局。微调满意后此按钮消失。

│ ○ 🛏️ 床  160×200  0°    │
│ ○ 📝 书桌 120×60   0°    │

│ ○ 💺 椅子 #1 40×40 0°   │
│ ○ 💺 椅子 #2 40×40 0°   │
│                           │
│ [+ 添加家具]               │
│                           │
│ ↩ 撤销   ↪ 重做  [↺ 恢复] │
│                           │
│ ← 回去看方案               │

```

**[↺ 恢复]** 按钮：将当前方案的所有家具恢复到算法初始位置。相当于"撤销所有手动的移动/旋转"。

### 画布交互

**选中态**：
```
        ●  ← 旋转手柄
   ┌────┬────┐
   │         │
   │ 🛏️ 床  │  ×
   │160×200 │
   └────┴────┘
  浮层: "通道 65cm ✓"
```

| 操作 | 方式 | 约束/反馈 |
|------|------|----------|
| 移动 | 拖拽主体 | 不超出房间边界 |
| 旋转 | 拖拽顶部圆形手柄 | 15° 吸附 |
| 快速旋转 90° | 右键点击 | 0/90/180/270° |
| 删除 | Delete 键 / × 按钮 | — |
| 取消选中 | 点击空白 / Esc | — |

**碰撞处理**：
- 拖拽中重叠 → 两者轮廓变红色半透明
- 释放仍重叠 → 自动回弹到最近可用位置
- 系统替用户处理了冲突，不需要手动调整

**添加家具**：
1. 点击 `[+ 添加家具]`
2. 弹浮层选择类型
3. 浮层关闭 → 画布进入放置模式
4. **鼠标跟随显示家具幽灵预览**（半透明，显示精确位置和碰撞状态）
5. 点击画布 → 放置 → 自动选中
6. Esc → 取消放置

### 导出

右上角"导出"按钮 → 弹出导出预览：

┌──────────────────────────┐
│ 导出方案                   │

## 八、跨标签状态与边界保护

### 8.1 状态保持

```
🏠 房间设置  → 尺寸和门窗始终保留
🪑 选择家具  → 清单和数量始终保留（改房间后轮廓位置重置，数量不变）
✨ 布局方案  → 方案索引保留，家具或房间变更后自动重排
✋ 微调      → 家具位置保留，重新布局后覆盖
```

### 8.2 无房间时的标签保护

用户还没创建房间时，点击"选择家具"或"布局方案"或"微调"标签：

```
不报错、不弹窗，温和引导：
- 标签可以点进去
- 面板显示: "🏠 请先创建房间"
- 画布显示: 空画布 + 中间提示"选择一个模板开始"
- 用户不会看到错误状态或崩溃
```

### 8.3 状态变更传播

| 用户操作 | 系统反应 |
|---------|---------|
| 改了房间尺寸 | 回到方案标签时自动重排（静默，不弹窗） |
| 增减了家具 | 同上 |
| 切换方案（Step 4 有微调） | 确认提示"当前微调将被丢弃，确定切换？" |
| 微调后回到方案标签 | 方案卡片显示"已手动调整"标记 |
| 点击模板（已有房间） | 确认提示"当前房间将被替换，确定吗？" |
| 在已占用的墙段上加门窗 | 自动偏移到不重叠位置，满墙时提示 |
| 家具放不下 | 方案标签提示"空间有限"，列出能排下的和放不下的 |

## 九、空状态与边界

**首次打开**：画布居中显示四个模板卡片（大圆角+阴影），底部"或自定义尺寸"。左侧面板正常展示。选一个后卡片消失。

**极小房间 (< 2m²)**：提示"建议至少 2×2m"，不创建，输入框保留数值。

**门/窗宽度边界**：40-200cm，拖拽到极限时停住（不弹回）。

**家具超出房间**：拖拽时不可超出房间边界，边界处卡住。

## 十、动画

| 场景 | 时长 | 缓动 | 说明 |
|------|------|------|------|
| 铺满画布 | 300ms | ease-out | 创建房间后自动执行一次 |
| 标签切换 | 150ms | ease | 面板淡入淡出 |
| 方案切换 | 400ms | ease-out | 家具从旧位滑到新位 |
| 选中元素 | 200ms | ease-out | 蓝色边框从中心扩散 |
| 删除元素 | 150ms | ease-in | 缩小+淡出 |
| 碰撞回弹 | 250ms | ease-out | 回到最近可用位置 |
| 添加门/窗 | 200ms | ease-out | 从点击点展开 |
| 添加家具（放置后） | 200ms | ease-out | 幽灵变实体 |

所有 ≤ 400ms，不阻碍操作，不循环播放。

## 十一、键盘快捷键

| 快捷键 | 作用 | 适用范围 |
|--------|------|---------|
| Ctrl+0 / Cmd+0 | 铺满画布 | 所有标签 |
| Ctrl+Z | 撤销（房间/门窗/家具） | **所有标签** |
| Ctrl+Y | 重做 | **所有标签** |
| Delete / Backspace | 删除选中元素 | 门/窗/家具 |
| ← → | 切换布局方案 | 方案标签 |
| Esc | 取消选中 / 退出放置 | 所有标签 |
| 空格 + 拖拽 | 平移画布 | 所有标签 |
| Enter（输入框内） | 确认创建 | 房间设置 |

> Ctrl+Z 覆盖所有操作，不只是微调。包括：房间尺寸修改、门窗添加/移动/删除、家具增减（数量级操作需谨慎——家具数量变更通过 [+] 操作，一般不撤销，但位置/旋转可撤销）。
