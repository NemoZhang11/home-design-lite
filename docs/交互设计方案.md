# 交互设计方案 — 流程驱动的布局绘图体验

> 版本: v0.1 | 日期: 2026-07-27 | 状态: 讨论稿
> 本文聚焦核心的**布局图绘制功能**（不考虑 LLM 个性化生成），旨在解决当前 Demo 交互不够利落优雅的问题。

---

## 一、交互问题诊断

### 1.1 当前 Demo 的核心问题

| 问题 | 表现 | 根因 |
|------|------|------|
| **模式切换割裂体验** | 用户需在"画户型/放家具/智能布局"三个模式间手动切换，每次切换都是工作流中断 | 编辑器思维（面向 CAD 用户），而非流程思维（面向普通业主） |
| **空画布吓人** | 首次打开看到空白画布+十字光标+"点击放置墙点"——普通用户不知道从何开始 | 缺少起点引导，没有明确的"第一步" |
| **侧边栏过载** | 200px 内塞入了模式按钮×3、家具卡片×7、建筑元素×2、房间尺寸表单×3、参数面板×2、操作按钮×5——共约 20 个交互元素 | 把所有功能平铺展示，不做阶段性聚焦 |
| **门/窗放置不直观** | 需先知道"在画户型模式下点击门卡片→然后移到墙上点击"——没有视觉线索提示 | 放置流程跨两个区域（侧边栏+画布），且状态变化没有明确反馈 |
| **AI 输入是断头路** | 标题栏的输入框看似核心功能，回车后仅显示"开发中"——用户预期崩塌 | 功能占位符与真实能力不匹配 |
| **智能布局是独立模式** | 需要主动切换到 layout 模式才会触发，而不是作为流程的自然步骤 | 功能孤立，与用户的"我想看看怎么摆家具"需求脱节 |
| **视觉层级不清晰** | 所有按钮外观接近（圆角+白底+边框），重要操作和次要操作视觉权重相同 | 缺乏信息架构设计 |

### 1.2 目标用户画像

```
年轻家庭 / 租房党 / 装修小白
  ↓
想做的事： "我这有个 3m×4m 的房间，帮我看看怎么摆家具"
  ↓
不想做的事： 学习模式切换、理解墙段是什么、记住快捷键
  ↓
期望的体验： 告诉我怎么开始 → 我选房间尺寸 → 我选家具 → 你帮我摆 → 我微调 → 完事
```

---

## 二、核心设计原则

1. **流程驱动，不切换模式** — 用户顺着步骤自然推进，而不是自己决定"现在该用什么模式"
2. **所见即所得** — 在画布上直接交互，不在侧边栏填写参数后再看效果
3. **渐进式披露** — 每一步只展示当前需要的控件，其他内容折叠/隐藏
4. **默认就有东西** — 首次打开就展示示例房间，而不是空白画布
5. **AI 输入是起点，不是装饰** — 即使后端 LLM 未就绪，输入框也应提供预设模板等即时反馈

## 三、交互流程设计

### 3.1 整体流程概览

```
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 房间设置                                           │
│  设定尺寸 + 放置门窗               ← 替代"画户型"模式        │
├─────────────────────────────────────────────────────────────┤
│  Step 2: 家具选择                                           │
│  选择需要摆放的家具               ← 替代"放家具"模式（简化版）│
├─────────────────────────────────────────────────────────────┤
│  Step 3: 自动布局                                            │
│  一键生成 + 方案切换              ← 替代"智能布局"模式        │
├─────────────────────────────────────────────────────────────┤
│  Step 4: 微调 (可选)                                         │
│  拖拽微调 + 添加/删除/旋转家具     ← 保留"放家具"模式的编辑能力 │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 Step 1: 房间设置

**目标**：用户用最简单的方式定义房间轮廓。

```
┌──────────────────────────────────────────────────────────┐
│  标题栏: 🏠 房间改造工具              [AI输入框...]        │
├───────────┬──────────────────────────────────────────────┤
│ ① 场景选择 │                                              │
│ ┌──────┐  │                                              │
│ │儿童房 │  │          画     布     区     域               │
│ │主卧   │  │                                              │
│ │书房   │  │    (展示示例房间平面图 + 尺寸标注)               │
│ │客厅   │  │                                              │
│ │自定义 │  │    尺寸: 400cm × 300cm                        │
│ └──────┘  │    墙上有门/窗占位符                             │
│           │                                              │
│ ┌────────┐│                                              │
│ │ 下一步→ ││                                              │
│ └────────┘│                                              │
├───────────┴──────────────────────────────────────────────┤
│  状态: 选择一个模板或自定义尺寸 → 开始设计                  │
└──────────────────────────────────────────────────────────┘
```

**交互细节**：

- **场景卡片**：5 个场景卡片（儿童房/主卧/书房/客厅/自定义），点击即选择。选择后画布立即显示对应尺寸的房间平面图（含默认门窗位置）。
- **"自定义"卡片**：点击后在画布上出现两个拖拽手柄或输入框，让用户设定宽×高。
- **门窗放置**：选择场景后，画布房间的四条墙上显示虚线占位符。用户点击某面墙即可添加门/窗，拖拽调整位置和宽度。**不需要进入任何"模式"**。
- **空状态处理**：无保存状态时，默认加载"儿童房 4m×3m"示例，让用户立刻看到东西。

### 3.3 Step 2: 家具选择

**目标**：用户勾选需要的家具，系统自动排入房间。

```
┌──────────────────────────────────────────────────────────┐
│  标题栏: 🏠 房间改造工具                                  │
├───────────┬──────────────────────────────────────────────┤
│ ② 需要哪些家具？│                                          │
│           │                                              │
│ □ 床 160×200│       画       布       区       域          │
│ □ 书桌 120×60│                                           │
│ □ 衣柜 100×60│    (当前房间 + 门窗渲染)                    │
│ □ 椅子 40×40│                                            │
│ □ 沙发 180×80│   已选家具显示在房间角落                        │
│           │    (淡色占位, 等待布局)                         │
│ 已选: 3件  │                                              │
│ ┌────────┐│                                              │
│ │ ✨ 生成布局││                                              │
│ └────────┘│                                              │
├───────────┴──────────────────────────────────────────────┤
│  状态: 已选择 3 件家具，点击"生成布局"自动排列              │
└──────────────────────────────────────────────────────────┘
```

**交互细节**：

- **勾选式选择**：家具目录变为复选框列表。勾选后家具即加入"待布置"清单。
- **数量微调**：每个家具项目可点击 +/- 调整数量（如 2 把椅子）。
- **尺寸预览**：勾选后，画布上房间内显示对应的家具淡色轮廓（带旋转方向），但位置暂定在房间边侧，不参与布局。
- **即时反馈**：底部显示"已选 X 件家具"，按钮"✨ 生成布局"变为可用。
- **与 Step 1 关系**：用户可回到 Step 1 修改房间尺寸，已选的家具清单保留。

### 3.4 Step 3: 自动布局 + 方案浏览

**目标**：一键生成多套布局方案，左右切换对比。

```
┌──────────────────────────────────────────────────────────┐
│  标题栏: 🏠 房间改造工具                                  │
├───────────┬──────────────────────────────────────────────┤
│ ③ 选择布局方案│                                          │
│           │                                              │
│ ○ 方案 A   │      画      布      区      域               │
│ ● 方案 B   │                                              │
│ ○ 方案 C   │   (渲染完整房间 + 家具 + 尺寸标注)              │
│           │                                              │
│           │    床 160×200    ←尺寸标注                     │
│           │    通道 65cm ✓   ←合规性标记                    │
│ ┌───┐     │                                              │
│ │ ◀ │ │ ▶ │    [最终结果展示，不再有模式概念]                │
│ └───┘     │                                              │
│           │                                              │
│ 方案B特点: │   关键尺寸：                                   │
│ 床头靠西墙│   · 通道宽度 65cm ✓                            │
│ 书桌靠窗采光│  · 衣柜门可开 ✓                               │
│           │   · 床不靠窗 ✓                                 │
├───────────┴──────────────────────────────────────────────┤
│  状态: 方案 B — 3/6 件家具 · 通道 65cm                   │
│  [← 返回选家具]                    [进入微调 →]            │
└──────────────────────────────────────────────────────────┘
```

**交互细节**：

- **三方案差异化**：方案 A（靠墙紧凑）、方案 B（分区布局）、方案 C（居中宽敞），在侧边栏以 radio 按钮切换。
- **方案卡片信息**：当前方案的名称、特点描述、关键尺寸标注直接显示在画布上。
- **合规性标记**：关键通道尺寸旁显示 ✓/✗，让用户快速判断方案是否合理。
- 底部有"← 返回选家具"和"进入微调 →"两个动作按钮，保持流程可进退。

### 3.5 Step 4: 微调 (仅有需要的用户进入)

**目标**：提供拖拽调整能力，但不强制用户使用。

```
┌──────────────────────────────────────────────────────────┐
│  标题栏: 🏠 房间改造工具           [添加家具] [导出图片]     │
├───────────┬──────────────────────────────────────────────┤
│ ④ 微调布局 │                                             │
│           │                                             │
│ 家具列表   │      画      布      区      域                │
│ ┌────────┐│                                             │
│ │ 🛏 床  ││   (家具可拖拽 + 旋转手柄)                      │
│ │ 📝 书桌 ││                                             │
│ │ 🗄 衣柜 ││  选中家具显示:                               │
│ │ 💺 椅子 ││  · 拖拽移动 · 旋转手柄                        │
│ └────────┘│  · 尺寸标注 · 删除按钮                         │
│           │                                             │
│ ┌────────┐│                                             │
│ │ + 添加  ││                                             │
│ └────────┘│                                             │
│           │                                             │
│ 撤销/重做 │                                             │
│ ↩ ↪       │                                             │
├───────────┴──────────────────────────────────────────────┤
│  状态: 拖拽调整家具位置 · 滚轮缩放 · 选中可删除            │
└──────────────────────────────────────────────────────────┘
```

**交互细节**：

- **侧边栏精简**：只显示家具列表（当前已放置的家具清单）+ "添加家具"按钮 + 撤销/重做。
- **选中即操作**：点击画布上的家具即选中，显示蓝色边框 + 旋转手柄，右侧不弹出参数面板。
- **旋转手柄**：选中家具顶部出现圆形旋转手柄，拖拽旋转，吸附 15° 增量。
- **删除**：选中后按 Delete 键，或点击家具右上角的小 × 按钮。
- **添加家具**：点击"添加"展开浮层面板选择家具类型→点击画布放置。
- **导出图片**：右上角"导出图片"按钮，保存为 PNG。

### 3.6 状态栏精简

当前状态栏承担了太多角色，需要精简：

- **左**：当前步骤指示（Step 1/4 → Step 2/4 → ...）
- **中**：关键状态提示（如"已选 3 件家具"）
- **右**：仅在需要时出现（如错误提示、操作确认）

**移除**：固定提示"💡 拖拽家具 · 滚轮缩放 · 右键删除"（这些应通过 UI 暗示而非文字告诉用户）

## 四、视觉布局方案

### 4.1 布局结构

```
┌──────────────────────────────────────────────────────────────┐
│  顶栏: 产品名 + 步骤指示器 + AI输入框(保留占位)  |  导出/反馈    │
├──────────────────────────────────────────────────────────────┤
│  Step 内容面板     │                                        │
│  (随步骤变化)      │            画布区域                      │
│  宽 220-260px     │     (始终居中显示房间平面图)               │
│                   │                                        │
│  仅显示当前步骤     │   比例尺: 1cm = 1px                     │
│  所需控件          │   Canvas 800×600                       │
│                   │                                        │
├──────────────────────────────────────────────────────────────┤
│  底栏: 当前步骤 (1/4) · 状态文本 · 快捷操作按钮               │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 视觉风格建议

- **配色**：浅色/白色主背景，去掉深色标题栏，改用白色+浅灰分割
- **圆角**：保留 12-16px 大圆角容器
- **阴影**：柔和阴影（已做得不错）
- **字体**：保持 -apple-system 系统字体族
- **图标**：保持 emoji 图标（降低开发成本）

### 4.3 响应式策略

保持原有决策：PC 为主，手机仅做 CSS 响应式折叠（不做触屏编辑）。

- PC（≥1024px）：完整四步骤 + 画布编辑
- 平板（768-1024px）：步骤面板可折叠为顶部步骤条
- 手机（<768px）：仅展示查看模式（方案浏览），步骤面板隐藏

## 六、需讨论的决策点

### A. 步骤指示还是自由模式？

**方案 A（推荐）**：固定四步骤，用户必须按顺序推进
- 优点：引导性强，用户不会迷路
- 缺点：灵活性低，高级用户可能觉得受限

**方案 B**：保留"自由模式"入口，但在空状态时给出引导提示
- 优点：兼顾新用户引导和高级用户自由
- 缺点：实现复杂度高，两种模式需要维护两套逻辑

### B. 门窗放置方式？

**方案 A（推荐）**：Step 1 中直接在画布墙上点击放置
- 双击或点击墙 → 出现门/窗占位符 → 拖拽调整位置和宽度
- 不需要侧边栏切换到"门"或"窗"卡片

**方案 B**：保持当前侧边栏卡片点击激活 + 点击墙放置
- 更符合直觉（先选工具再操作）
- 但多了一步操作

### C. 画布是否允许自由手绘墙？

**方案 A**：不做手绘墙，仅通过尺寸输入生成矩形房间
- 与产品路线图中的 MVP 范围一致
- 大幅降低复杂度

**方案 B**：保留手绘能力作为高级功能，默认隐藏
- 满足极少数高级用户需求
- 需要维护两套房间创建逻辑

### D. 选中参数面板放在哪里？

**方案 A（推荐）**：选中家具/门/窗后，参数直接在画布上显示（浮层或手柄）
- 不占用侧边栏空间
- 操作位置更接近目标

**方案 B**：当前方案，侧边栏下方弹出参数面板
- 不影响画布视野
- 但视觉上脱离操作目标
