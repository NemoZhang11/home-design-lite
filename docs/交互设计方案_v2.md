# home-design-tool 交互设计方案 v2

> 版本: v2.0 | 日期: 2026-07-27 | 状态: 待讨论
> 
> 本方案聚焦**布局图绘制核心功能**的交互流程和用户体验设计，不涉及 LLM 个性化生成。
> 当前会话仅用于方案讨论与确认，不做实际开发。

---

## 一、设计决策记录

以下为基于 v1 讨论稿的四项决策确认：

| 决策点 | 结论 | 含义 |
|--------|------|------|
| A. 流程 vs 自由模式 | **引导式步骤 + 自由跳转** | 顶栏展示四步标签，用户可随时点击任意步骤切换；不强制顺序，但提供引导线索 |
| B. 门窗放置方式 | **画布上直接点击墙放置** | 无需侧边栏激活模式，在画布上点击/双击墙段即可弹出添加菜单 |
| C. 手绘墙能力 | **模板 + 自由绘制并展示** | 房间设置同时提供"快速模板"和"自由绘制"两种入口，让用户看到所有可选方式 |
| D. 参数面板位置 | **画布浮层 / 操作手柄** | 选中元素后参数控件直接在画布上显示（浮层或拖拽手柄），不占用侧边栏 |

## 二、整体布局

### 2.1 页面结构

```
┌─────────────────────────────────────────────────────────────────┐
│ 顶栏                                                                     │
│  ┌──────┐  🏠 房间设置  🪑 选择家具  ✨ 布局方案  ✋ 微调    [AI输入...] │
│  │ 返回  │  ● Step 1     ○ Step 2    ○ Step 3     ○ Step 4   [导出] │
│  └──────┘                                                            │
├──────────┬──────────────────────────────────────────────────────────┤
│          │                                                          │
│ 左侧面板  │                    画布区域                               │
│          │                                                          │
│ (内容随   │           Konva Stage (800×600)                          │
│  当前步骤  │                                                          │
│  变化)    │    始终展示房间平面图（如有）                               │
│          │                                                          │
│ 宽 240px  │                                                          │
│          │                                                          │
├──────────┴──────────────────────────────────────────────────────────┤
│ 底栏                                                                     │
│ 步骤 1/4 · 下一步提示 · 💬 反馈                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 布局关键规则

- **顶栏**：始终固定，展示四步步进标签（可点击切换）、AI 输入框（保留占位）、导出按钮
- **左侧面板**：宽度 240px，内容随当前激活步骤切换。不同步骤切换时面板内容**平滑过渡**（无突兀的闪现）
- **画布**：始终居中，展示当前房间平面图。任何步骤中的操作都实时反映在画布上
- **底栏**：精简为步骤位置提示 + 状态文本 + 反馈入口

### 2.3 步骤标签状态规则

```
[ 🏠 房间设置 ]  [ 🪑 选择家具 ]  [ ✨ 布局方案 ]  [ ✋ 微调 ]
     ● 激活           ○ 可访问        ○ 可访问        ○ 可访问
```

- **所有步骤标签始终可点击**——用户可以随时跳转到任意步骤
- 激活的步骤以高亮/填充色标记
- 未激活的步骤以轮廓/半透明显示
- 步骤标签左侧不显示数字序号（避免暗示"必须按顺序"），而是用图标表示步骤主题

## 三、Step 1：房间设置（核心交互）

### 3.1 左侧面板内容

```
┌─────────────────────┐
│  🏠 房间设置         │
│                     │
│  ┌─────┬─────┐      │
│  │ 👶  │ 🛏️  │      │
│  │儿童房│ 主卧 │      │
│  │4×3m │5×4m │      │
│  ├─────┼─────┤      │
│  │ 📚  │ 🛋️  │      │
│  │ 书房 │ 客厅 │      │
│  │3×3m │6×4m │      │
│  └─────┴─────┘      │
│                     │
│  ┌─────────────────┐│
│  │ ✏️ 自定义尺寸     ││
│  │ 宽 [400] × 高 [300]││
│  │         [创建]  ││
│  └─────────────────┘│
│                     │
│  ─── 或 ───         │
│                     │
│  [✏️ 自由绘制墙线]   │
│  (点击画布逐点绘制)   │
│                     │
│  当前房间: 4m×3m     │
│  已有门窗: 门×1 窗×1  │
├─────────────────────┤
│ 状态: 点击墙放置门窗   │
└─────────────────────┘
```

### 3.2 房间创建——三种入口

#### 入口 A：快速模板

| 模板 | 尺寸 | 默认家具 | 适用场景 |
|------|------|---------|---------|
| 👶 儿童房 | 4m×3m | 床、书桌、衣柜 | 最常见的小房间改造 |
| 🛏️ 主卧 | 5m×4m | 床、衣柜、梳妆台 | 主卧室布局 |
| 📚 书房 | 3m×3m | 书桌、书架、椅子 | 小型书房 |
| 🛋️ 客厅 | 6m×4m | 沙发、茶几、电视柜 | 客厅布局 |

**交互细节**：
- 点击模板卡片 → 画布立即渲染对应尺寸的房间矩形 + 默认门/窗位置
- 模板卡片在选中时显示视觉反馈（边框高亮 + 轻微放大）
- 切换模板时画布平滑过渡（非闪烁重建）

#### 入口 B：自定义尺寸

**交互细节**：
- 点击"自定义尺寸"区域 → 输入框获得焦点
- 输入宽/高（单位 cm），支持范围 100-1000cm
- 点击"创建"或按回车 → 画布渲染指定尺寸的房间
- 输入框有格式校验：仅数字，超出范围时显示提示

#### 入口 C：自由绘制墙线

**交互细节**：
- 点击"自由绘制墙线"按钮 → 画布切换为绘制模式（十字光标 + 提示）
- 点击画布添加墙点（吸附 10cm 网格）
- 点击回到起点或接近起点时闭合房间（与当前 Demo 的绘制逻辑一致）
- 绘制过程中左侧面板显示："已添加 X 个墙点，点击起点或按 Enter 闭合"
- 绘制过程中可随时点击其他步骤标签中断绘制（已绘制的墙点保留）
- 闭合后自动退出绘制模式，左侧面板切回房间信息摘要

### 3.3 门窗放置交互

**激活方式**（两种，用户可任选）：

- **方式 A**：双击画布上的墙面 → 弹出快捷菜单
- **方式 B**：单击墙面选中墙段 → 墙段上出现 "+" 按钮 → 点击按钮弹出菜单

**快捷菜单**：

```
      ┌──────────────┐
      │ 🚪 添加门     │
      │ 🪟 添加窗户   │
      └──────────────┘
```

**放置后交互**：
- 门/窗出现在点击位置的墙段上
- 默认宽度：门 80cm，窗 100cm
- 门默认：向内开，左铰链
- 放置后立即进入**选中状态**（见下文）

### 3.4 门/窗选中状态交互

选中门或窗后，画布上显示操作控件：

```
         ←→ 拖拽调整宽度
         ────
    ───┐      ┌───    ← 墙线
       │  🚪  │
    ───┘      └───    ← 墙线
   ● 铰链点    ──      ← 拖拽沿墙滑动
              (圆弧)   ← 开门方向示意

叠加浮层显示:         ←→ 80cm
```

**交互功能**：
| 操作 | 手势 | 反馈 |
|------|------|------|
| 沿墙移动 | 按住门/窗主体拖拽 | 跟随鼠标沿墙滑动，吸附到合理位置 |
| 调整宽度 | 拖拽门/窗边缘手柄 | 实时显示新宽度，最小40cm最大200cm |
| 切换开门方向 | 点击门的弧线区域 | 内外开切换，弧线反向 |
| 切换铰链侧 | 双击门主体 | 左右铰链切换，门图形翻转 |
| 删除 | 按 Delete 键 或 点击门/窗上的 × 按钮 | 元素从画布移除 |

**选中取消**：点击画布空白区域或按 Esc → 取消选中，手柄和浮层消失。

### 3.5 Step 1 边缘状态

| 状态 | 画布 | 左侧面板 | 操作引导 |
|------|------|---------|---------|
| 首次打开 (无保存) | 显示欢迎画面 + 四个模板卡片叠层 | 面板正常展示 | "选择一个模板开始" |
| 已有保存内容 | 恢复保存的房间 | 显示当前房间信息 | "点击墙添加门窗" |
| 绘制中未闭合 | 显示已绘制的墙段 + 最后一个点的吸附指示线 | "已添加 X 个墙点" | "点击起点闭合" |
| 房间已创建 | 显示闭合房间 + 网格 + 尺寸标注 | 显示房间尺寸 + 门窗数量 | "切换到'选择家具'继续" |

```
└─────────────────────┘
```

### 4.2 家具选择交互

**家具列表** 展示所有可用家具类型，每项包含：
- 图标 + 名称
- 尺寸标注（宽×高，单位 cm）
- 数量调节器（− / 数量 / +）

**交互细节**：
- **默认状态**：所有家具数量为 0
- **增加数量**：点击 [+] → 家具数量 +1，画布上出现该家具的**半透明占位轮廓**
- **减少数量**：点击 [−] → 家具数量 -1（最低 0），画布上对应占位轮廓消失
- **键盘输入**：点击数字区域可手动输入数量（最大 99）
- **占位轮廓**：新加入的家具在画布上显示灰色半透明矩形（不参与碰撞），排列在房间右侧空闲区域，右上角标注家具名称

### 4.3 画布状态

- **已有房间渲染**：显示 Step 1 设置的房间（墙体 + 门窗）
- **已选家具轮廓**：勾选的家具在房间内以半透明轮廓显示，初始位置排列在房间右侧临时区域
- **轮廓数量动态更新**：增减数量时，轮廓实时添加或移除

### 4.4 底部操作

- "已选 X 件家具，共 Y 件" —— 实时更新的摘要
- "✨ 生成布局" 按钮：
  - **可用条件**：至少选择 1 件家具
  - **不可用时**：灰色禁用状态，hover 提示"请至少选择一件家具"
  - **点击行为**：跳转到 Step 3（布局方案）并自动触发布局生成

### 4.5 Step 2 边缘状态

| 状态 | 画布 | 按钮状态 | 引导 |
|------|------|---------|------|
| 未选择家具 | 显示空房间 + 门窗 | 禁用（灰色） | "点击 +/- 选择需要摆放的家具" |
| 已选家具 | 房间内显示半透明家具轮廓 | 激活 | "点击'生成布局'查看方案" |
| 房间尺寸变更后回此步 | 轮廓位置重置到临时区域（保持数量） | 激活 | "已选家具保持不变，重新生成布局即可" |

## 五、Step 3：布局方案

### 5.1 左侧面板内容

```
┌─────────────────────┐
│  ✨ 布局方案         │
│                     │
│  方案选择             │
│                     │
│  ● 方案 A · 推荐     │
│    📐 靠墙紧凑布局    │
│    ✓ 通道 65cm       │
│    ✓ 床不靠窗        │
│    ✓ 衣柜门可开      │
│                     │
│  ○ 方案 B            │
│    📐 动静分区布局    │
│    ✓ 通道 72cm       │
│    ✓ 书桌靠窗采光    │
│                     │
│  ○ 方案 C            │
│    📐 居中宽敞布局    │
│    ✓ 通道 90cm       │
│    ⚠ 衣柜贴窗边     │
│                     │
│  ─────────────       │
│  [🔄 重新生成]        │
│                     │
├─────────────────────┤
│  ← 返回选家具         │
│  进入微调 →           │
└─────────────────────┘
```

### 5.2 布局生成交互

**触发方式**（两种）：
1. 从 Step 2 点击"生成布局" → 自动进入 Step 3 并触发
2. 在 Step 3 点击"重新生成" → 再次运行布局算法

**生成过程反馈**：
```
画布上显示加载状态：
┌──────────────────────┐
│                      │
│    ✨ 正在生成方案...   │
│                      │
│    ────── ▓▓░░ ────  │
│    方案 A ▓▓▓▓░░░░    │
│    方案 B ▓▓▓▓▓▓░░    │
│    方案 C ▓▓▓▓▓▓▓▓    │
│                      │
└──────────────────────┘
```
（~300ms 动画，让用户感知到系统在工作，而非瞬间闪现）

### 5.3 方案切换交互

**面板交互**：
- 点击 radio 按钮或方案卡片 → 画布切换到对应布局
- 当前选中的方案高亮显示（蓝色边框 + 填充背景）
- 各方案旁展示关键指标：
  - ✓ 合规项（绿色）——通道宽度满足、功能区域合理
  - ⚠ 提醒项（橙色）——家具靠近窗户等需要注意但非错误
  - ✗ 违规项（红色）——严重不合理（极少出现，布局算法已过滤）

**键盘交互**：
- ← → 方向键在方案间切换（画布即时更新）

### 5.4 画布状态

每套方案在画布上展示内容：
1. **房间轮廓**：墙体 + 门窗（与 Step 1 一致）
2. **家具渲染**：实体矩形填充，不同家具用不同颜色区分
3. **家具标签**：每件家具上方标注名称（如 "🛏️ 床"）
4. **尺寸标注**：关键通道宽度标注（如 "65cm"）+ 家具自身尺寸
5. **合规标记**：每个标注旁显示 ✓ 或 ⚠

```
画布示例（局部）：
┌──────────────────────────────────┐
│                                  │
│  ┌─── 窗户 150cm ───┐            │
│  │         │                    │
│  │  ┌──────┐    ┌──────┐       │
│  │  │ 🛏️床  │    │📝书桌 │       │
│  │  │160×200│    │120×60 │       │
│  │  └──────┘    └──────┘       │
│  │     │  65cm ✓          │    │   ← 通道标注
│  │  ┌──────┐                  │
│  │  │🗄️衣柜 │                  │
│  │  │100×60│                  │
│  │  └──────┘                  │
│  │         │                    │
│  └─── 🚪门 80cm ───┐           │
└──────────────────────────────────┘
```

### 5.5 底部操作

- **← 返回选家具**：跳回 Step 2，家具选择数量保留
- **进入微调 →**：跳转到 Step 4，方案布局保留为微调起点

### 5.6 Step 3 边缘状态

| 状态 | 画布 | 面板 | 引导 |
|------|------|------|------|
| 无家具可布局 | 显示上一个步骤的房间 | 显示"请先选择家具" | "← 返回选家具" |
| 布局生成中 | 加载动画 | 方案 radio 禁用 | "正在排列..." |
| 布局完成 | 显示选中方案的完整布局 | 三个方案可选 | "切换方案对比，或进入微调" |
| 从 Step 2 携带家具变更返回 | 重新生成布局 | 方案刷新 | 旧方案被替换，显示新方案 |

- 撤销栈深度：最多 50 步
- 按钮禁用状态：无可撤销/重做操作时按钮变灰

## 七、交叉步骤状态保持（关键）

### 7.1 状态保活规则

| 数据 | 步骤间跳转时 | 说明 |
|------|------------|------|
| 房间尺寸 & 墙线 | 始终保留 | 从 Step 1 创建后，在任何步骤都不会丢失 |
| 门窗位置 | 始终保留 | 从 Step 1 添加后，在所有步骤可见 |
| 家具选择数量 | Step 2 ↔ 3 ↔ 4 间保留 | 回到 Step 1 修改房间时保留（但轮廓位置重置） |
| 布局方案数据 | Step 3 → 4 传递 | Step 4 的微调基于 Step 3 选中的方案 |
| 微调后的家具位置 | Step 4 内保留 | 回到 Step 3 重新生成时覆盖 |
| 选中状态 | 切换步骤时清除 | 避免跨步骤残留选中高亮 |

### 7.2 跨步骤冲突处理

| 场景 | 行为 | 用户感知 |
|------|------|---------|
| Step 4 微调后 → 点 Step 1 改房间尺寸 | 保留家具数量，清空位置（房间已变） | 切换回 Step 2/3/4 时自动提示"房间已变更，需要重新布局" |
| Step 3 浏览方案 → 点 Step 2 增减家具 | 方案切换回 Step 3 时自动重新生成 | 无缝，用户看到的是更新后的方案 |
| Step 4 微调后 → 点 Step 3 切换方案 | 覆盖微调结果，问用户确认 | 弹出确认框："切换方案将丢弃当前的微调修改" |

## 八、动画与过渡

### 8.1 步骤切换动画

- 左侧面板内容切换：**淡入淡出**（150ms），新面板从右侧滑入
- 步骤标签激活状态：底部边框下划线平滑过渡（200ms）
- 画布内容：不重新渲染——**画布始终保持状态不变**，只在相关数据变更时更新

### 8.2 元素动画

| 场景 | 动画 | 时长 | 缓动 |
|------|------|------|------|
| 选中家具 | 蓝色边框从中心向外扩散 | 200ms | ease-out |
| 布局生成 | 家具从临时位置滑动到最终位置 | 400ms | ease-out |
| 添加门/窗 | 从点击点展开到完整尺寸 | 200ms | ease-out |
| 删除元素 | 缩小 + 淡出 | 150ms | ease-in |

### 8.3 状态反馈动画

- 合规标记 (✓) → 绿色小勾，带弹跳出现（300ms）
- 违规标记 (⚠) → 橙色感叹号，带脉冲闪烁（提示注意，不闪烁超过 2 次）
- 错误操作（如碰撞）→ 红色闪烁 + 回弹（200ms）

## 十二、响应式策略

遵循产品定位阶段的决策：**不做独立移动版，一套响应式 Web**。

### 12.1 断点设计

| 宽度 | 布局 | 功能 |
|------|------|------|
| ≥1024px (桌面) | 完整四列布局：顶栏 + 左侧面板 + 画布 + 底栏 | 全部功能可用 |
| 768-1023px (平板) | 左侧面板折叠为可切换的 Drawer | 全部功能可用，面板收起时画布占满 |
| <768px (手机) | 所有面板收起，全屏画布 | **仅查看模式**：可查看方案、切换方案，不能编辑 |

### 12.2 手机端简化

- 步骤标签收窄为图标 + 小字，横向排列
- 左侧面板隐藏，通过底部"⚙ 设置"按钮弹出底部 Sheet
- 画布占满屏幕宽度
- 仅支持：查看方案、切换方案（左右滑动或点击箭头）
- 不支持：墙线绘制、门窗放置、家具微调

## 十四、附录：完整用户旅程示例

### 示例场景：用户布置儿童房

```
1. 打开页面
   → 看到欢迎画面：四个模板卡片叠在画布上方 + 左侧面板显示模板选择
   → 点击"👶 儿童房 4m×3m"
   → 画布立即渲染 400×300 房间 + 默认门窗
   → 面板切换为房间信息摘要："当前房间: 4m×3m · 门×1 窗×1"
   → 底栏显示: "Step 1/4 · 点击墙添加门窗"

2. 添加一扇窗
   → 双击画布上方的墙
   → 弹出菜单「🚪 添加门 / 🪟 添加窗户」
   → 点击"🪟 添加窗户"
   → 窗户出现在点击位置，宽度 100cm
   → 拖拽窗户边缘到 150cm → 松手，窗户更新
   → 底栏: "Step 1/4 · 窗户已添加"

3. 点击"🪑 选择家具" 标签
   → 面板切换为家具清单
   → 点击床的 [+] → 数量变为 1，画布出现床的半透明轮廓
   → 点击衣柜的 [+] × 2 → 数量变为 2，画布出现两个衣柜轮廓
   → 点击书桌的 [+] → 数量变为 1
   → 面板底部: "已选: 床×1 衣柜×2 书桌×1 · 共 4 件家具"
   → "✨ 生成布局 (4)" 按钮亮起

4. 点击"✨ 生成布局"
   → 自动跳转到 Step 3
   → 画布上显示加载动画 ~300ms
   → 方案 A 自动渲染：床靠左墙、衣柜靠右墙、书桌靠窗
   → 面板显示三个方案 radio，方案 A 选中
   → 切换方案 B → 画布平滑更新
   → 方案 C: "⚠ 衣柜贴窗边" → 用户觉得不合适，切回方案 A

5. 点击"进入微调 →"
   → 进入 Step 4
   → 面板显示家具清单 + 撤销/重做 + 添加按钮
   → 用户拖拽书桌稍微左移 10cm
   → 选中衣柜 → 拖拽旋转手柄 90° → 衣柜变为横向
   → 满意后点击右上角"导出" → 保存 PNG

6. 想调整房间尺寸
   → 点击"🏠 房间设置" 标签
   → 修改宽度 400→450
   → 点击"🪑 选择家具" → 家具数量保留，但位置重置
   → 点击"✨ 生成布局" → 新房间尺寸下重新生成方案
   → 继续微调 → 完成
```
