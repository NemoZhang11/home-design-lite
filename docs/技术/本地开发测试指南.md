# 本地开发与测试指南

> last updated: 2026-07-28 · v5.1

## 环境

| 项目 | 值 |
|------|-----|
| 包管理器 | npm |
| 构建工具 | Vite 6 |
| 开发服务器 | `npx vite --port 3000` |
| 访问地址 | `http://localhost:3000/home-design-lite/` |
| 生产构建 | `npm run build` (`tsc -b && vite build`) |
| 输出目录 | `dist/` |

## 快速启动

```powershell
# 进入项目目录
cd D:\home\家装布置\home-design-tool

# 启动开发服务器（热更新, 自动打开浏览器）
npx vite --port 3000

# 或者通过 npm script（同样效果）
npm run dev
```

打开浏览器访问 `http://localhost:3000/home-design-lite/`

> `Ctrl+Shift+R` 硬刷新清除缓存，确保加载最新代码。

## 构建 & 预览生产版本

```powershell
npm run build          # TypeScript 检查 + Vite 打包
npm run preview        # 预览生产构建（dist/ 目录）
```

## 运行测试

```powershell
npm test               # 单元测试 (vitest)
npm run test:e2e       # E2E 测试 (Playwright)
```

## PowerShell 后台启动（Windows 专用）

开发服务器进程绑定在 PowerShell 窗口上，关闭窗口即终止。如需后台运行：

```powershell
# 方式1: 新窗口最小化（推荐）
Start-Process powershell -ArgumentList "-NoExit", "-Command", "cd 'D:\home\家装布置\home-design-tool'; npx vite --port 3000" -WindowStyle Minimized

# 方式2: 直接后台进程
Start-Process -NoNewWindow npx -ArgumentList "vite", "--port", "3000"
```

## 关闭开发服务器

```powershell
# 关闭所有 node 进程
Get-Process -Name "node" -ErrorAction SilentlyContinue | Stop-Process -Force
```

## 已知问题 & 调试技巧

- 开发服务器 `Ctrl+C` 偶尔不响应 → 用上面 `Stop-Process -Name node` 强制结束
- `npm run dev` 后改了 `vite.config.ts` 里的 `base` 路径需要重启
- 画布不显示 → 检查控制台是否有 Konva 或 TypeScript 错误
- 状态异常 → 浏览器 DevTools → Application → Local Storage → 清除 `home-design-tool-state`
- 家具拖拽无响应 → 确认当前在"✋ 微调"标签下
